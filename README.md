# 한끼온

기획서 「AI 기반 학생 맞춤형 영양 관리 및 편식 케어 앱」의 핵심 흐름을 구현한 최소 웹앱입니다. HTML, CSS, JavaScript만 사용해 설치와 빌드 과정이 없습니다.

## 실행

`index.html`을 Chrome 또는 Edge로 열면 바로 사용할 수 있습니다.

브라우저에서 파일 저장을 제한하는 경우, 이 폴더에서 다음 명령으로 실행한 뒤 `http://localhost:8000`을 여세요. 파일로 열 때와 서버로 열 때의 저장 공간은 서로 다릅니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

## 사용 방법

1. 키, 몸무게, 만 나이, 계산식 기준 성별, 활동량과 음식 취향을 입력하고 저장합니다.
   ‘성장·식사 상담 준비’에서는 희망 몸무게를 상담용 메모로 남기고, 실천할 식사 습관과 다음 상담 날짜를 선택할 수 있습니다. 입력 중에는 ‘성장과 식사 계획’에 미리 보기가 나타나며, 프로필 저장을 눌러야 보관됩니다. 선택 항목은 비워 둘 수 있습니다.
2. 오늘 급식 또는 매점 간식에서 먹은 메뉴를 누릅니다. 한 번 누를 때 표시된 1인분이 기록되며, 같은 메뉴도 여러 번 추가할 수 있습니다.
   ‘음식 직접 입력’ 탭에서는 음식 이름을 검색하면 예시 칼로리가 표시됩니다. 먹은 양을 0.5인분, 2인분 등으로 바꾸면 열량도 바뀌며 검색 결과를 누르면 기록됩니다. 검색되지 않는 음식은 ‘찾는 음식이 없나요? 직접 추가하기’를 열어 이름, 먹은 양 설명, 확인한 총 열량을 직접 입력합니다.
3. 오늘의 합계, 필요량 추정치와의 차이, 취향에 따른 추천, 최근 7일 합계를 확인합니다.
4. 잘못 입력한 기록은 옆의 삭제 버튼으로 지웁니다. 공용 기기에서는 ‘프로필과 전체 기록 삭제’를 사용합니다.

## 구현 범위

- 학교 메뉴 12개와 예시 열량·단백질 데이터
- 음식 이름으로 예시 음식 32개 검색, 먹은 인분에 따른 열량 계산, 검색 결과 원터치 기록
- 목록에 없는 음식의 이름·먹은 양·열량 직접 입력 및 저장
- 만 13~18세 프로필과 하루 에너지 필요량 추정
- 희망 몸무게 상담 메모, 식사 습관, 상담 날짜 저장과 실시간 미리 보기
- 청소년 성장도표 안내 및 식사량·점검 기간을 상담에서 정하도록 안내
- 원터치 식사 추가, 개별 삭제, 날짜별 합계와 7일 그래프
- 선호 종류·누적 선택 빈도·남은 추정량을 활용한 규칙 기반 추천
- 브라우저 localStorage 저장, 날짜 변경 시 오늘 화면 갱신
- 모바일 화면과 키보드 조작 지원

단순화를 위해 회원가입, 서버, 실제 학교 식단 연동, 사진 인식, 외부 AI API, 교사용 관리 화면, 푸시 알림은 포함하지 않았습니다. 예시 메뉴는 `app.js`의 `FOODS` 배열, 추가 검색 음식은 `SEARCH_FOODS` 배열에서 수정할 수 있습니다. 자동 검색은 내장 예시 목록 조회이며 인터넷 음식 검색이나 AI 영양 추정은 아닙니다. 직접 입력한 음식은 식사 기록으로 저장됩니다. 검색한 음식은 ID와 인분을 저장하므로 데이터 구조나 열량을 바꿀 때 기존 기록 처리도 검토해 주세요.

## 계산과 추천

키·몸무게만으로 필요 열량을 확정하지 않고, 나이·성별·활동량을 추가로 입력받습니다. [Health Canada의 DRI 에너지 필요량 추정식](https://www.canada.ca/en/health-canada/services/food-nutrition/healthy-eating/dietary-reference-intakes/tables/equations-estimate-energy-requirement.html)의 13세 및 14~18세 계수와 성장 에너지를 적용하고 정수 kcal로 반올림합니다. 활동량은 간단한 자기 평가이므로 공식 PAL 측정을 대체하지 않습니다. 한국 학생용 공식 권고나 진단을 구현한 것은 아닙니다.

추천은 피하는 종류와 남은 추정량에 맞지 않는 메뉴를 제외하고, 명시한 선호 종류, 기록 빈도, 예시 단백질 값을 기준으로 정렬한 상위 3개입니다. 남은 추정량은 섭취 상한선이 아니며, 추천 결과를 성장기 학생의 식사 제한이나 체중 감량 기준으로 사용해서는 안 됩니다. 학교 영양교사의 검토를 거쳐 실제 서비스로 확장해야 합니다.

입력 정보는 현재 기기의 브라우저에만 저장됩니다. 암호화·로그인·기기 간 동기화는 없으며, 저장 공간이 차단되면 화면에 안내합니다. 음식 취향 제외는 알레르기 필터가 아닙니다. 전체 섭취량이 아니라 사용자가 기록한 음식만 합산합니다.

## 성장·식사 상담 준비

이 앱의 사용 대상은 만 13~18세입니다. 키만으로 평균·이상 체중을 만들어 제시하거나, 희망 체중에 따른 칼로리 제한과 체중 변화 완료일을 자동 계산하지 않습니다. [질병관리청 소아청소년 성장도표](https://knhanes.kdca.go.kr/knhanes/grtcht/main.do)는 소아청소년의 성장 상태를 평가하는 참고 자료이며, 앱은 원본 확인 링크를 제공합니다. 성장도표의 수치나 백분위를 내부에서 추정하지 않습니다.

[NIDDK 청소년 건강 안내](https://www.niddk.nih.gov/health-information/weight-management/take-charge-health-guide-teenagers)에 따라 성장 속도와 건강 상태를 함께 고려하고, 개인별 식사 계획은 영양교사·의료진과 상의하도록 구성했습니다. 희망 몸무게는 사용자가 상담 때 이야기할 메모로만 보관하고 하루 필요량 추정치에 반영하지 않습니다. 체중 차이, 감량 속도, 칼로리 적자나 목표 달성일도 산출하지 않습니다.

상담 날짜는 사용자가 선택한 점검 일정이며 체중 목표의 기한이 아닙니다. 알림 예약이나 메시지 전송 기능은 없습니다. 기존 브라우저 프로필과 식사 기록은 유지되며 새 선택 항목이 없는 이전 데이터도 읽습니다.

## 파일과 검증

- `index.html`: 화면
- `style.css`: 화면 스타일과 모바일 대응
- `app.js`: 예시 메뉴, 계산, 추천, 저장과 화면 처리
- `app.test.cjs`: 계산식, 입력 검증, 일별 합계, 추천, 저장 데이터 검증

Node.js가 있으면 다음 명령으로 핵심 로직을 검증합니다.

```powershell
node --test app.test.cjs
```
